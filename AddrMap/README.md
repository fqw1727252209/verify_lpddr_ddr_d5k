# AddrMap 地址映射测试

本目录用于存放地址映射相关的验证用例和脚本。

## 1. 测试点提取 (Test Plan)

基于测试计划，地址映射（AddrMap）的验证功能点主要分为两大类：

### 1.1 自定义地址映射功能 (addr_gen模块验证)
主要验证从系统发送的离散CHI地址到DMU内部连续物理地址的映射正确性，包含两类子场景：

- **不截位离散地址到连续地址映射功能**
  - **场景描述**：检查**不截位**的情况下，离散地址到连续地址映射的正确性。
  - **测试方法**：配置 `dmu_reg_addr_region_0/1/2/3_ch0/1` 寄存器进行空间配置（例如 region0 设为 2~4GB，region1 设为 512~542GB）。将截位寄存器 `dmu_reg_addr_strip_bits_hi/lo_ch0/ch1` 配置为 0（即不截位）。
  - **期望结果**：初始化完成后发送写后读请求，能正确映射为连续地址，访问和数据比对正确。

- **截位离散地址到连续地址映射功能**
  - **场景描述**：检查**截位**的情况下，离散地址到连续地址映射的正确性。
  - **测试方法**：空间配置同上。将截位寄存器 `dmu_reg_addr_strip_bits_hi/lo_ch0/ch1` 配置为不同于0的测试值（实际项目结合 N/S 节点数量配置，如 2的幂次方截位规则）。
  - **期望结果**：发写后读激励，判断地址映射正确性，数据比对正确。

### 1.2 控制器连续地址到 DRAM 接口离散地址映射 (DDRC行列地址映射验证)
主要验证 DDRC 内部将 UIF 连续地址转换为 DIMM 端的行列等物理地址（cs, row, col, ba, bg）的正确性：

- **默认配置映射**
  - **场景描述**：采用 `row[16:0] -> cs[1:0] -> ba[1:0] -> col[5:0] -> bg[2:0]` 这种线性或默认映射方式。
  - **测试方法**：按照规范将对应的 `csrColPos`, `csrBaPos`, `csrCsPos`, `csrRowPos` 等寄存器配置为默认值（如 Col0Pos=3, Col1Pos=4... Row16Pos=29）。
  - **期望结果**：发送数据访问请求，数据读写完全正确。

- **随机配置映射**
  - **场景描述**：在满足模型位宽的前提下，做随机化的映射配置。
  - **测试方法**：通过约束，生成合理的随机映射寄存器配置序列。
  - **期望结果**：无论怎么打散和随机组合引脚映射关系，底层读写的数据应该严格一致。

- **性能最优映射**
  - **场景描述**：采用符合最佳性能需求的映射配置（如结合 Bank Hash）。
  - **测试方法**：写入具体的性能推荐配置（例如开启 `CTL_BANK_HASH_EN` 等）。
  - **期望结果**：读写正确且能够验证到相应的性能特征或地址交织行为。
